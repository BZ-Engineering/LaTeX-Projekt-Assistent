## Version 1.0

Erste Version.

- Geführter Assistent in 7 Schritten (Projekt, Personen, Titelseite, Gliederung, Zotero, GitHub, Erstellen)
- LaTeX-Vorlage (KOMA-Script) mit Titelseite, Eigenständigkeitserklärung in Ich-/Wir-Form,
  Verzeichnissen inkl. Formelverzeichnis, Kopfzeile mit Logo, IEEE-Zitierstil mit Quellenart,
  Anhang zur KI-Nutzung
- Automatischer Literaturabruf aus einer Zotero-Sammlung (Better BibTeX) bei jedem Build
- VS-Code-Einstellungen: Build beim Speichern, Zotero-Zitate per Alt+Shift+Z, Auto-Pull, Erweiterungsempfehlungen
- Git-Repository mit erstem Commit, optional GitHub-Repository (Konto oder Organisation, privat/öffentlich)
- GitHub Actions baut bei jedem Push das PDF und veröffentlicht es als Release „Aktuelles PDF“
- Windows und macOS
